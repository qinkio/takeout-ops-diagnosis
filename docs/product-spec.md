# 产品说明

## 目标用户

管理多个品牌或门店、使用平台导出文件进行周复盘的餐饮运营人员。

## 输入

每行对应一个品牌、门店、平台和周期。支持美团外卖、淘宝闪购（饿了么）和京东外卖。字段规范见 `skills/takeout-business-review/references/input-schema.md`。

## 输出

- 数据问题清单
- 重点门店清单
- 规则命中与来源行
- 待补证据或待人工确认的候选任务
- 机器可读的校验、诊断和任务 JSON

## 非目标

- 不获取平台授权或调用平台接口
- 不代替用户操作活动、推广、菜单或价格
- 不自动触达顾客
- 不以演示阈值代替品牌经营目标

## 成功标准

- 相同输入得到相同诊断结果
- 所有结论能够追溯到规则和源行
- 数据阻断时不继续生成经营归因
- 候选任务在人工确认前不进入执行状态
