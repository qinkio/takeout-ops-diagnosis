# 公开方法说明

本仓库将个人工作经验抽象为可运行的公开演示规则。公开文件不包含原公司文档名、客户或门店信息、本机路径、平台账号信息和真实经营数据。

## 演示阈值

- 收入变化死区 `10%`
- 平台方向差异死区 `5%`
- 连续下滑演示条件：三个可比周期、第三期较第一期下降至少 `20%`，且第一期预计收入高于 `2500`
- 评分演示关注线 `4.6`
- 评价小样本线 `10`

这些数字用于验证规则引擎和任务闭环，不是行业基准，也不是任何平台的官方建议。实际使用时应结合门店阶段、品类、城市、客单、样本量和品牌目标配置。

## 诊断原则

1. 先判断数据能否比较，再计算变化。
2. 先描述事实和贡献，再提出待验证原因。
3. 不跨品牌、门店、平台或不一致周期合并归因。
4. 候选动作必须列出证据、负责人、观察周期和验证指标。
5. 涉及平台操作和顾客触达的动作必须由用户人工确认并在有权限的系统中执行。
