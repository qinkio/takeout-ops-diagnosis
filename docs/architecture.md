# 系统架构

```text
用户上传数据
  -> 字段映射与规范化
  -> 数据质量校验
  -> 品牌/门店/平台/周期分组
  -> 确定性规则诊断
  -> 证据与来源行绑定
  -> 候选任务生成
  -> 人工确认与后续验证
```

核心脚本分为三层：

1. `validate_and_calculate.mjs` 校验数据粒度、周期、0 值和核心数值，并计算可复核指标。
2. `execute_rules.mjs` 在可比较范围内执行规则，输出门店优先级、事实和证据。
3. `create_action_loop.mjs` 将规则命中映射为候选任务，补充证据要求、负责人角色、观察周期和验证指标。

`run_takeout_review.mjs` 负责串联三层流程，并生成 Markdown、CSV 和 JSON 结果。
